黑金慕夏塔羅占卜｜GitHub Pages 靜態版

內容
1. index.html：網站首頁
2. style.css：版面與黑金視覺樣式
3. script.js：抽牌、解牌中畫面、隨機牌與詳細解讀功能
4. mucha：九張慕夏塔羅展示牌面
5. og.png：社群分享預覽圖
6. favicon.svg：瀏覽器圖示
7. .nojekyll：讓 GitHub Pages 直接發布靜態檔案

本機使用
直接以瀏覽器開啟 index.html 即可使用，不需要安裝套件或啟動伺服器。

GitHub Pages 發布方式
1. 建立新的 GitHub repository。
2. 將本資料夾內的所有檔案上傳到 repository 根目錄。
3. 到 GitHub repository 的 Settings → Pages。
4. 在 Build and deployment 選擇 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，然後儲存。
6. 等待 GitHub 顯示網站網址。

功能
- 單張指引與三張牌陣
- 不重複隨機抽牌
- 1.8 秒「解牌中」Loading 畫面
- 牌面核心、提問連結、行動建議與溫柔提醒
- 三張牌整體訊息
- 桌面及行動版響應式版面

隱私
使用者輸入的問題只存在目前瀏覽器畫面中，不會上傳或儲存。
